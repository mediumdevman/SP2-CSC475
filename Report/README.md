# Progress Report (ISMIR 2024 template)

Build: `latexmk -pdf main.tex` (or upload this folder to Overleaf). Submit `main.pdf`.

| File | Who edits it |
|---|---|
| `main.tex` | Shared sections — coordinate in the group chat before big edits |
| `sections/status_jackson.tex` | Jackson |
| `sections/status_brooklynn.tex` | Brooklynn |
| `sections/status_jaiya.tex` | Jaiya |
| `references.bib` | Anyone (add entries, then `\cite{key}` them in the text) |

Everything in red `[TODO: ...]` must be filled in or deleted before submitting.
Status words in the tables: `\stDone`, `\stPart`, `\stNone`.

Template files live in `template/` (`ismir.sty`, `cite.sty`, `IEEEtran.bst`, `figs/`) and come from
https://github.com/ismir/paper_templates (2024) — don't edit them. `.latexmkrc` tells LaTeX to look in that folder.
