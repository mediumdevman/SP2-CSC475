\texttt{Song/song\_scorer.py} computes CLAP zero-shot scores on the three axes based on a 
high and low similarity prompt for each axis. The model is showing strong results,
however, it scores songs based on a randomly chosen 10 second window which can cause 
the scores to be inconsitent with the overall vibe of the song depending on the window chosen. 
The next step will be to adjust the method to use the entire song to compute the scores 
as well as test the songs on a pretrianed checkpoint made for music instead of the 
current default checkpoint. Using the mood/theme subset of the MTG\_Jamendo dataset, test 
songs are being selected using the mood/theme labels to ensure there will be a variety 
of songs, and the first eight songs have been labelled Low/Mid/High on energy, 
happiness and warmth. Beyond the CLAP scoring, next steps will be to build a model
that uses the librosa features, and one that also uses the CLAP embeddings to compute scores.
